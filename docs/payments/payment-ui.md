# Payment UI

Admin payment UI additions:

- Payments dashboard
- Manual payment form
- Pending Interac verification
- Invoices list and details
- Refund list and actions
- Webhook event list
- Reconciliation page
- Payment settings page

Customer UI additions:

- Invoice view
- Invoice print view
- Receipt view
- Interac instructions on payment detail pages

Admin payment pages use the admin sidebar and do not expose public cart or checkout navigation.
